# My Portfolio


**My Portfolio** is a personal portfolio website designed to showcase my skills, interests, projects, and information about myself. The website consists of four pages that allow visitors to learn more about who I am while also demonstrating my web development and programming skills.

This project was created to build my online presence and provide a platform where potential employers, collaborators, and peers can view my work and technical abilities.

---

##  Features

* Four responsive web pages
* Personal profile and introduction
* Skills showcase
* Interests and hobbies section
* Contact form
* Responsive design for different screen sizes
* Interactive hover effects and styling

 live :https://purritylportfolio.netlify.app/


### Clone the Repository

```bash
git clone https://github.com/your-username/my-portfolio.git
```

### Run Locally

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install and launch the Live Server extension.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
